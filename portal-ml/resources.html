Plano de Especialista · 4 semanas

Recursos & plano de estudo

Tudo que sustenta a trilha reunido num lugar: o cronograma das 4 semanas até o exame, os livros, os whitepapers que valem a pena, onde praticar e a matriz de competências. Pensado pra quem mira uma vaga Sênior ou Especialista em ML e MLOps.

4 semanas, 4 focos. Cada semana tem um tema central e uma dinâmica de estudo. 🔴 High é prioridade máxima; 🟡 Medium complementa; 🟢 Low é desejável.
1
Dias 1–7 · Core Knowledge
Fundamentos ML + DSA + AWS
Testar conceitos fundamentais
High Aprendizagem de Máquina (teoria)
High Regressão vs Classificação
High Redes Neurais (fundamentos)
High Python, Estruturas de Dados puras
High Algoritmos estilo LeetCode
High AWS Practitioner (serviços core)
High Arquitetura de Nuvem básica
Medium Treveil, Introducing MLOps (leitura rápida)
DINÂMICA
Testar conceitos fundamentais, propor desafios de código em Python puro (pilhas, matrizes, bitwise/XOR) e design de infraestrutura AWS básica.
2
Dias 8–14 · Data & Dev
Engenharia + Dados + Ambiente
Cenários práticos de engenharia
High Feature Engineering
High SQL (consultas, otimização)
High Modelagem de Dados Transacional
High Manipulação de Dados Não Estruturados
High Docker (containerização de modelos)
High Linux (comandos críticos para deploy)
High Git (versionamento)
Medium Testes de Software (dados)
Medium Metodologia Ágil em times de dados
DINÂMICA
Cenários práticos de isolamento de ambientes com Docker, comandos críticos de Linux para deploy, testes unitários para funções de transformação de dados.
3
Dias 15–21 · System Design
Arquitetura MLOps End-to-End
Desafios de arquitetura reais
High Desenho de Solução MLOps
High CI/CD para ML (CD4ML, Martin Fowler)
High Feature Store (arquitetura)
High Model Registry (versioning + stages)
High AWS Well-Architected ML Lens
High Google Cloud MLOps, Levels 0/1/2
Medium Infra as Code (IaC)
Medium ML Design Patterns (Lakshmanan)
DINÂMICA
Desafios de arquitetura com problemas reais de negócio. Avaliação de system design usando AWS, Google Cloud e Martin Fowler como referência.
4
Dias 22–28 · Validação
Simulado + Gap Filling
Modo exame
High Simulado geral (modo exame)
High 360DigitMG, MLOps Interview Q&A
High Awesome MLOps, gap vocabulary
High Revisão ativa (active recall)
Medium Engenharia reversa de questões
Medium Identificação de gaps de última hora
DINÂMICA
Modo Simulado. Questões de múltipla escolha e código, avaliação de respostas com base na literatura recomendada. 360DigitMG e Awesome MLOps somente nesta semana.

Chip Huyen (Ed. Brasileira)
O recurso mais alinhado com nível Especialista. Cobre produção, trade-offs reais e decisões de sistema. S1: caps. 1-2 (framing, métricas de negócio); S2: caps. 5-6 (feature engineering, dados); S3: caps. 7-9 (deployment, monitoramento, drift); S4: caps. 10-11 (MLOps platform, edge cases).
