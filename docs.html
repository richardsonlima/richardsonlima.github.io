Quick Start

Initialize a safe agent in less than 10 lines of code.

from aeon.kernel import AeonAgent

agent = AeonAgent(name="Nexus-01")
# Define a System 2 Axiom
@agent.axiom("max_temp")
def check_thermal(val):
    return min(val, 400)

Safety Axioms

Axioms are deterministic code gates that run before any LLM action is executed. They represent the "System 2" of your agent.

Violation Mode Behavior
OVERRIDE Silently correct the value to a safe limit.
BLOCK Stop execution and raise a SafetyViolation.
ESCALATE Request human-in-the-loop authorization.
