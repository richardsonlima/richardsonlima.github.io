Modo entrevista

Para qualquer algoritmo canônico, responda 10 dimensões. Se conseguir, você opera acima da média. Use os flashcards para treinar recuperação aleatória — pressão de entrevista é prática, não talento.

Como usar

1. Revise o framework abaixo.
2. Vá para os flashcards, leia a pergunta, formule resposta mentalmente.
3. Revele a resposta de referência e marque acertou / errei.
4. Atalhos: ␣ revelar · → próximo · A acertei · E errei

01

Framework — 10 dimensões por algoritmo

Aplica a TODO algoritmo canônico
01
Problema
O que resolve?
Tipo de tarefa (regressão / classificação / clustering / ranking) e tipo de output esperado.
02
Hipótese
Qual hipótese assume?
Linearidade, independência condicional, normalidade dos erros, smoothness, MDP, manifold de baixa dimensão.
03
Falha
Quando falha?
Cenários onde a hipótese central é violada — exemplos concretos com dataset/condição.
04
Performance
Complexidade?
Treino e inferência — O(n), O(n log n), O(n²), O(n·d²). Memória.
05
Compreensão
Interpretável?
Glass box (coeficientes, regras) vs black box. Ferramentas: SHAP, LIME, feature importance, attention.
06
Escala
Escala bem?
Milhões de amostras? Paralelizável? Online learning? Distribuído?
07
Robustez
Sensível a outlier?
MSE eleva ao quadrado → muito sensível. Hinge, Huber, MAE → mais robusto. Árvores → quase imunes.
08
Pré-processamento
Precisa feature scaling?
KNN, SVM, redes neurais, gradient descent: sim. Árvores e ensembles de árvores: não.
09
Regularização
Como evita overfitting?
L1/L2, dropout, early stopping, pruning, max_depth, data augmentation, CV.
10
Avaliação
Qual métrica usar?
Regressão → RMSE/MAE/R². Classificação → F1/AUC/log-loss. Ranking → NDCG/MAP. Calibração → Brier.
